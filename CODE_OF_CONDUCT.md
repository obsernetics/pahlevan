# Code of Conduct

## Our pledge

Pahlevan follows the [CNCF Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md).

By participating in this project you agree to abide by it. This applies to every
project space: GitHub issues and pull requests, code review comments, commit
messages, discussions, and any Pahlevan channel or event, online or in person.

We keep the canonical text in one place rather than copying it here, so that
Pahlevan always tracks the current CNCF version. Please read it in full at the
link above.

## Scope

The Code of Conduct applies to all contributors, maintainers, and users acting
in a Pahlevan space, and to individuals representing the project in public.

## Reporting

If you experience or witness behavior that violates the Code of Conduct, report
it. You do not need to be certain that something is a violation to report it.

Choose whichever route you are most comfortable with:

1. **Project maintainers.** Email `team@obsernetics.com`. This reaches the
   Pahlevan maintainers listed in [MAINTAINERS.md](MAINTAINERS.md).
2. **CNCF Code of Conduct Committee.** Email `conduct@cncf.io`. Use this route
   for anything involving a maintainer, for anything you would rather not send
   to the project, or if a project report does not get a satisfactory response.

Pahlevan is currently a small project with a single maintainer, so route 2 is
the right choice whenever the report concerns that maintainer or when you want
an independent reviewer. We would rather you escalate than stay silent.

## What to include

A useful report says what happened, where it happened (a link is ideal), who was
involved, and whether it is ongoing. Include anything you think would help
someone who was not there understand the incident.

## What happens next

- Maintainers acknowledge Code of Conduct reports within **3 business days**.
- Reports are handled confidentially. We do not share the reporter's identity
  with the reported person without the reporter's consent.
- Maintainers will not act as adjudicators in a report that concerns
  themselves; such reports are referred to the CNCF Code of Conduct Committee.
- Outcomes may include a private warning, a request for a public apology, a
  temporary ban from project spaces, or a permanent ban, depending on severity
  and pattern.

## Enforcement authority

Maintainers may remove, edit, or reject comments, commits, code, issues, and
other contributions that violate the Code of Conduct, and may temporarily or
permanently ban any contributor for behavior they judge inappropriate,
threatening, offensive, or harmful.

Serious cases and any appeal are escalated to the CNCF Code of Conduct
Committee, whose decision is final.
