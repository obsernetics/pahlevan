# Maintainers

This file lists the people who can approve and merge changes to Pahlevan. See
[GOVERNANCE.md](GOVERNANCE.md) for how maintainers are added, what they are
expected to do, and how they are removed.

## Current maintainers

| Name | GitHub | Affiliation | Areas |
|---|---|---|---|
| Reza Ghanbari | [@r21gh](https://github.com/r21gh) | Obsernetics | Everything: eBPF data plane, operator and CRDs, build and release |

Pahlevan has exactly one maintainer today. That is an honest statement of the
project's size, not an aspiration. Growing this table is the project's single
most important governance goal, and the path to joining it is written down in
[GOVERNANCE.md](GOVERNANCE.md#becoming-a-reviewer).

## Reviewers

None yet. Reviewers are contributors with review authority but without merge

## Contact

- General and technical discussion: GitHub issues and pull requests on
  [obsernetics/pahlevan](https://github.com/obsernetics/pahlevan).
- Code of Conduct reports: `team@obsernetics.com`, or `conduct@cncf.io` for
  anything involving a maintainer. See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
- Security vulnerabilities: do **not** open an issue. Follow
  [SECURITY.md](SECURITY.md).
