pahlevan read-only dashboard

What each workload actually does

This dashboard is read-only. It cannot change a policy, a mode or a profile, and it has no endpoint that would.

It has no accounts of its own either. Paste a Kubernetes bearer token above and every read is checked against that identity with a SubjectAccessReview, so you see exactly the namespaces your own RBAC allows and nothing else. The token stays in this tab and is sent only in the Authorization header.

A token for your own user: kubectl create token <serviceaccount>, or whatever your cluster's identity provider issues.

All assets are served from the dashboard binary. No external origin, no inline script.
