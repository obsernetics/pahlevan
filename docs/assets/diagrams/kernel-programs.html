Data plane

Seven kernel programs, one loop

Each observes during the learning window and refuses during enforcement, scoped to a single cgroup. The bottom two need no BPF LSM, so they work on stock kernels.

nginx python3 bash one cgroup = one container

lsm/capable Every capability check, plus the task's sets
tracepoint/sys_enter Every syscall with its six arguments
kprobe/commit_creds The moment privilege changes, syscall or not
uretprobe/readline Commands typed at a prompt, builtins included
